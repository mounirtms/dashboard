🔧 Step-by-Step Troubleshooting

Step 1: Check Browser Console

Press F12 or Ctrl+Shift+J to open Developer Tools, then check the Console tab for errors.

Common Errors to Look For:
  • 403 Forbidden - File permission issues
  • 404 Not Found - Missing files
  • MIME type error - Incorrect file types
  • Blocked by client - Browser extensions blocking requests

Step 2: Verify Notification Permissions

Check if your browser allows notifications from technostationery.com:

  • Chrome: Settings → Privacy and security → Site Settings → Notifications
  • Firefox: Preferences → Privacy & Security → Permissions → Notifications
  • Safari: Preferences → Websites → Notifications

Step 3: Test Service Workers

In Developer Tools, go to Application → Service Workers:

  • Look for OneSignal service workers
  • Check if they're registered and activated
  • Try updating/refreshing the service worker

Step 4: Clear Browser Data

Sometimes cached data causes issues:

  • Clear browser cache and cookies for technostationery.com
  • Unregister service workers
  • Hard refresh (Ctrl+F5)

🛠️ Technical Solutions

Common Issues and Fixes:

Issue: 403 Forbidden Errors

Cause: File permissions or security restrictions

Solution: Ensure files have proper permissions (644 for files, 755 for directories)

Issue: 404 Not Found Errors

Cause: Missing JavaScript files

Solution: Verify file paths and redeploy static content

Issue: MIME Type Errors

Cause: Server sending incorrect content types

Solution: Check .htaccess or server configuration for proper MIME types

Issue: Blocked by Client

Cause: Ad blockers or privacy extensions

Solution: Disable extensions temporarily or whitelist the site

📋 Verification Checklist

  • ✅ OneSignal App ID configured correctly
  • ✅ Service worker files accessible
  • ✅ Manifest.json file present with GCM sender ID
  • ⚠️ Check browser notification permissions
  • ⚠️ Verify HTTPS is enabled
  • ⚠️ Test in different browsers
