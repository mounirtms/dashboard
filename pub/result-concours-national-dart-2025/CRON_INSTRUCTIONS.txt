# Instructions for setting up automatic CSV updates

To automatically update the CSV file with the latest form submissions, you need to set up a cron job.

Run the following command to edit your crontab:
crontab -e

Then add one of the following lines depending on how often you want the CSV to be updated:

# Update every hour
0 * * * * /home/technadminy7/public_html/pub/result-concours-national-dart-2025/auto_update_csv.sh

# Update every 30 minutes
*/30 * * * * /home/technadminy7/public_html/pub/result-concours-national-dart-2025/auto_update_csv.sh

# Update every 15 minutes
*/15 * * * * /home/technadminy7/public_html/pub/result-concours-national-dart-2025/auto_update_csv.sh

# Update every day at 2 AM
0 2 * * * /home/technadminy7/public_html/pub/result-concours-national-dart-2025/auto_update_csv.sh

Save and exit the crontab editor.

The script will automatically log each update in the update_log.txt file.
