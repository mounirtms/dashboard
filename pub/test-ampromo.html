Debugging Steps:

  1. Open your browser's developer tools (F12)
  2. Go to the Console tab
  3. Check for any JavaScript errors
  4. Add products to your cart and check the console for Amasty Promo messages
  5. If you see "Amasty Promo is properly loaded", the JavaScript is working
  6. If you see "Amasty Promo is NOT loaded", there's a JavaScript issue

Common Issues:

  • JavaScript errors preventing Amasty Promo from loading
  • Conflicts with other JavaScript libraries
  • Missing or incorrect requirejs-config.js configuration
  • Cache issues preventing updated JavaScript from loading
