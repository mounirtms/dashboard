Essential commands and procedures for system administration

🔄 Service Management

# Restart all services systemctl restart httpd mysqld varnish redis php-fpm # Individual service restart systemctl restart httpd systemctl restart mysqld systemctl restart varnish systemctl restart redis # Check service status systemctl status httpd systemctl status mysqld systemctl status varnish
Tip: Always check service status after restart to ensure proper startup

📊 Performance Monitoring

# Check system resources htop free -h df -h # Check specific service performance systemctl status httpd --no-pager mysqladmin processlist varnishstat -1 # Network monitoring ss -tulpn iftop nethogs

💾 Log Analysis

# Apache error logs tail -f /etc/apache2/logs/error_log # MySQL slow query log tail -f /var/lib/mysql/slow-query.log # Varnish logs varnishlog -g request varnishncsa # System logs journalctl -f
Note: Use -f flag for real-time log following

🔍 Troubleshooting

# Check disk space df -h # Check memory usage free -h # Check running processes ps aux --sort=-%cpu | head -20 # Network connectivity ping google.com netstat -tlnp # Port availability lsof -i :80 lsof -i :443

Magento Specific Commands

# Clear cache php bin/magento cache:flush # Reindex php bin/magento indexer:reindex # Deploy static content php bin/magento setup:static-content:deploy # Check module status php bin/magento module:status # Compile DI php bin/magento setup:di:compile
Warning: Always backup before running Magento commands in production

🔒 Security Checks

# Check firewall status csf -l # View blocked IPs csf -g # Check failed login attempts grep "Failed password" /var/log/secure # Monitor active connections netstat -an | grep :80 | wc -l # Check file permissions find /home/*/public_html -type f -perm 777
