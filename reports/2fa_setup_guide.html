Guide d'activation de l'authentification a deux facteurs (2FA)

Protection de votre compte administrateur avec Google Authenticator
OBLIGATOIRE - Action requise
Action requise avant le 1er Juillet 2026.
A partir de cette date, l'acces au panneau d'administration necessitera un code de verification Google Authenticator a chaque connexion. Sans configuration prealable, vous ne pourrez plus vous connecter.
Pourquoi ?
Suite a l'audit de securite du 12 Juin 2026, nous renforçons la protection de tous les comptes administrateurs. La double authentification (2FA) empeche l'acces non autorise meme si votre mot de passe est compromis.
1 Installer Google Authenticator sur votre telephone

Telechargez l'application Google Authenticator depuis votre store :

Google Authenticator
Android / iOS
Microsoft Authenticator
Android / iOS
Authy
Android / iOS

Toutes ces applications sont compatibles. Nous recommandons Google Authenticator pour sa simplicite.

2 Acceder a votre profil administrateur

Connectez-vous au panneau d'administration :

https://technostationery.com/sysadminy/

Une fois connecte :

  • Cliquez sur votre nom d'utilisateur en haut a droite de l'ecran
  • Selectionnez "My Account" (Mon Compte)
  • Ou allez dans System > Permissions > All Users et cliquez sur votre nom
3 Ouvrir l'onglet "Two-Factor Settings"

Sur la page de votre profil, vous verrez plusieurs onglets a gauche :

  • Account Information
  • User Role
  • Two-Factor Settings ← cliquez ici

Dans l'onglet Two-Factor Settings, vous verrez :

  • Enable TFA : changez de "No" a "Yes"
  • Secret Key : votre cle secrete unique (ex: ABC123DEF456GHIJ)
  • QR Code : un code QR a scanner avec votre telephone
  • Security Code : champ pour verifier que tout fonctionne
4 Scanner le QR Code avec Google Authenticator

Sur votre telephone :

  • Ouvrez Google Authenticator
  • Appuyez sur le bouton "+" en bas a droite
  • Selectionnez "Scanner un QR code"
  • Pointez la camera vers le QR Code affiche sur votre ecran d'ordinateur
  • Un nouveau compte apparait dans Google Authenticator avec votre nom d'utilisateur
  • Un code a 6 chiffres s'affiche et change toutes les 30 secondes
Alternative : Si vous ne pouvez pas scanner le QR code, vous pouvez entrer la Secret Key manuellement dans Google Authenticator (bouton "+" > "Saisir une cle de configuration").
5 Verifier le code et sauvegarder

De retour sur votre ordinateur :

  • Dans le champ "Security Code", entrez le code a 6 chiffres affiche sur votre telephone
  • Cliquez sur "Check Code"
  • Si le code est correct, un message de confirmation apparait
  • Cliquez sur "Save User" en haut de la page
Important : Cliquez bien sur "Save User" apres la verification. Sans sauvegarde, la 2FA ne sera pas activee.
6 Tester la connexion avec 2FA

Apres avoir sauvegarde :

  • Deconnectez-vous du panneau d'administration
  • Sur la page de connexion, vous verrez maintenant un champ "Security Code" sous le mot de passe
  • Entrez votre nom d'utilisateur + mot de passe + code a 6 chiffres de Google Authenticator
  • Cliquez sur "Connexion"

Questions frequentes

Je ne vois pas l'onglet "Two-Factor Settings" sur ma page de profil

L'onglet n'apparait que si vous modifiez un utilisateur existant. Allez dans System > Permissions > All Users, puis cliquez sur votre nom d'utilisateur pour acceder a la page d'edition.

Le code de Google Authenticator ne fonctionne pas

Verifiez que l'heure de votre telephone est correcte. Sur Android : Google Authenticator > Parametres > Correction horaire pour les codes > Synchroniser. Sur iPhone : Reglages > General > Date et heure > Automatique.

J'ai change de telephone, comment recuperer mes codes ?

Contactez l'administrateur systeme (voir contacts ci-dessous). Il pourra reinitialiser votre 2FA et generer un nouveau QR code. Pensez a sauvegarder votre Secret Key dans un endroit sur lors de la configuration initiale.

Je ne peux pas scanner le QR code (camera en panne)

Utilisez l'option "Saisir une cle de configuration" dans Google Authenticator et entrez manuellement la Secret Key affichee sur votre ecran.

Le champ "Security Code" n'apparait pas sur la page de connexion

Videz le cache de votre navigateur et rechargez la page. Si le probleme persiste, contactez l'administrateur systeme.
